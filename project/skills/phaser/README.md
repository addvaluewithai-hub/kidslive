# KidsLive Phaser Skill Reference

Start with **[CATALOG.md](./CATALOG.md)**.

The uploaded skill instructions are preserved in five readable category files so they remain easy to inspect from GitHub and from future coding sessions without requiring the original ZIP. The catalog tells you which skill(s) to read for a task.

The source upload contained 25 Phaser skills. UI packaging files such as icons are intentionally not duplicated here because the repository uses these as engineering/design reference material; the full `SKILL.md` instruction content is preserved.
