## Scope
This delivery session hardens evidence for the already-built A6 English vertical slice. It does not add curriculum breadth, generalized A7 interactions, A8 progression/economy, or A11 persistence.

## Deterministic product proof
The A6 journey is exercised as one coherent chain rather than only as isolated delivery-session assertions:

1. Hub starts with English incomplete.
2. Learner enters English World through the production Hub/scene path.
3. A4 advances welcome → practice → assessment.
4. One wrong answer increments authoritative assessment attempts without granting completion.
5. A4 exposes and consumes the authored hint.
6. A normalized correct answer advances to celebrate.
7. Final authored completion creates exactly one A6 receipt.
8. The receipt has the bounded grant `a6:english-first-word-complete` and world change `english:first-word-star`.
9. Hub return visibly derives `First word learned ✓` from the deterministic slice state.
10. Re-entry recognizes previous completion without issuing a second grant.

Evidence is split across a pure deterministic integration test and one Playwright product-flow test that runs for both configured desktop and mobile projects and captures retry/hint, completion, changed-Hub, and safe-re-entry screenshots.
